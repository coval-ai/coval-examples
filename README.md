Examples for evaluating and monitoring AI agents with Coval's API and OpenTelemetry tracing.

## Examples

| Example | What it demonstrates |
| --- | --- |
| [Upload conversations](./upload-conversations) | Upload recordings from Twilio, Vapi, AWS, Google Cloud, or a signed URL. |
| [Launch runs](./launch-runs/launch_run.py) | Start an evaluation run through the Coval API. |
| [Generate test sets](./test-sets/generate_test_set.py) | Generate test cases with OpenAI and upload them to Coval. |
| [Voice agents](./voice-agents) | Add Coval OpenTelemetry tracing to Vapi, Pipecat, LiveKit, and Twilio agents. |

Each example includes its own configuration in the script or accompanying README. Start there for the required API keys, dependencies, and setup steps.
